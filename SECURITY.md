# Security

This repository is an offline research simulator. It does not authenticate users, communicate with chargers, or control physical hardware. Do not connect it directly to power electronics.

Use GitHub private vulnerability reporting if enabled by the repository owner. Otherwise open a minimal issue requesting a private reporting channel without publishing exploit details or secrets.

Federated model averaging is not a privacy guarantee. Q-tables and updates can reveal information about local experience. No secure aggregation, differential privacy, poisoning defense, or encrypted transport is implemented.
